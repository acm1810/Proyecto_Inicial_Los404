# Descripción
Este proyecto busca visibilizar y redistribuir el turismo en la Región de Valparaíso, 
enfocándose en destinos secundarios y menos conocidos.  
La propuesta consiste en una plataforma web que centraliza información de atractivos 
turísticos, permitiendo a los visitantes descubrir rutas alternativas y planificar sus viajes.

# Objetivo
Reducir la concentración turística en los cerros y sectores más populares, 
promoviendo experiencias en barrios, cerros y valles con baja visibilidad.

# Funcionalidades principales
- Recomendador de rutas alternativas por cerros.
- Catálogo de atractivos categorizados por barrios y actividades.
- Buscador con filtros de cercanía (ascensores, escaleras).
- Guardado de favoritos y bitácora de viaje.
- Sistema de reseñas comunitarias.
